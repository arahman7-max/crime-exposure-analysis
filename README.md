# Crime Exposure Analysis

## Academic Project

This repository contains an academic project completed as part of a university statistics/data analysis course. The code has been reorganized and documented for portfolio purposes. The original dataset was provided for academic use and is therefore not included in this repository.

## Overview

This project analyzes how exposure to crime influences the estimated probability of committing a crime. The analysis combines data visualization with regression modeling to evaluate treatment effects before and after an intervention while controlling for demographic and behavioral characteristics.

## Methods

The analysis includes the following approaches:

- Data visualization using ggplot2
- Difference-in-differences style linear regression
- Interaction effect analysis
- Multiple linear regression with demographic controls
- Model comparison

Regression models include controls for:

- Sex
- Race
- Social mimicry
- Treatment status
- Time (Before/After)
- Treatment-by-time interaction
